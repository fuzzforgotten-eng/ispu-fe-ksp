# ISPU-FE

Frontend ISPU — Vue 3 + Vite + Tailwind CSS 4.

## Prasyarat

- Node.js 18+ (disarankan 20+)
- npm 9+

## Setup

```sh
npm install
```

## Cara Running

Dev (hot-reload, akses via LAN):

```sh
npm run dev
```

Buka `http://localhost:5173`.

Build produksi:

```sh
npm run build
```
 
Preview hasil build:

```sh
npm run preview
```

## Script Lain

```sh
npm run lint    # cek + autofix ESLint
npm run format  # format src/ dengan Prettier
```
